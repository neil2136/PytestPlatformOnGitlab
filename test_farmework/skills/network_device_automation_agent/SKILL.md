## 目标

该 Skill 为资深网络设备自动化开发与测试工程师量身打造，帮助完成以下工作：

- 编写、重构、优化网络自动化脚本，适配华为、华三、思科等路由交换、防火墙、政企全网设备。
- 支撑自动化测试：设计测试用例、基于 Pytest 搭建测试框架、封装夹具、功能/回归自动化测试。
- 整理各厂商设备 CLI 命令，将手工配置转为批量自动下发脚本，做配置解析、日志分析、合规校验。
- 排查 SSH 登录、脚本报错、网络协议（OSPF/BGP/VLAN）配置故障，定位根因并给出修复方案。
- 对接 GitLab CI/Jenkins，将自动化脚本接入流水线，实现代码提交、自动测试、批量部署发布。
- 生成标准化项目结构、代码规范、开发文档，优化老旧代码，适配团队协作规范。

## 核心能力

1. 设备与协议知识
   - 内置网络设备原理、厂商命令、网络协议、自动化框架、测试工程专业知识。
   - 熟悉 Huawei/H3C/Cisco 通用配置风格与差异。

2. 代码与测试自动化
   - 将自然语言需求直接转成可运行 Python/Ansible 代码。
   - 自动加异常处理、重试、解耦设计、日志输出、参数化测试。
   - 一键搭建 Pytest 项目骨架，支持用例模板、夹具、参数化、批量执行。

3. 故障定位与日志分析
   - 解析脚本报错、设备 CLI 输出、SSH 登录失败、配置冲突。
   - 自动识别故障类型并给出定位思路、改代码、配置命令或修复建议。

4. CI/CD 与团队交付
   - 提供 GitLab CI/Jenkins 配置和项目脚手架，支持自动化代码提交、测试、部署。
   - 生成标准项目结构、README、开发文档、代码规范说明。

5. 定制化与迭代
   - 支持适配企业私有设备、内部私有命令、团队编码风格。
   - 能根据用户反馈迭代输出，保持方案与团队规范一致。

## 使用流程

1. 收集需求
   - 明确目标：开发脚本、测试方案、故障定位、CI 集成、文档整理。
   - 确认设备类型、厂商、操作系统、访问方式、已有代码、环境约束。

2. 分类决策
   - 如果是脚本开发/重构，则输出可运行脚本 + 异常处理 + 参数化设计。
   - 如果是测试支撑，则输出 Pytest 框架、夹具、测试用例、执行命令。
   - 如果是配置转换，则输出厂商兼容的批量下发脚本与配置模板。
   - 如果是故障定位，则输出故障分析、根因、修复命令/代码。
   - 如果是 CI/CD，则输出 GitLab CI/Jenkins Pipeline、执行步骤、发布方案。

3. 生成与校验
   - 生成结果时，优先保证：可运行性、供应商兼容、异常安全、复用性。
   - 对脚本和测试用例追加校验点：设备连接、命令执行、返回码、输出解析。
   - 对配置和日志分析添加“预期行为 vs 实际行为”说明。

4. 输出标准
   - 代码：清晰模块、注释、变量规范、错误处理、日志记录。
   - 测试：结构化用例、参数化覆盖、夹具复用、报告输出。
   - 文档：项目结构说明、使用说明、部署步骤、注意事项。
   - 故障定位：问题描述、诊断结论、修复建议、验证方法。

## 质量检查点

- 是否明确目标设备厂商和型号。
- 是否区分了手工配置与自动化批量下发。
- 是否生成了可执行的 Python/Ansible 代码。
- 是否加了 SSH/CLI 连接异常处理、超时重试。
- 是否覆盖了测试点、回归场景、参数化场景。
- 是否输出了 CI/CD Pipeline 片段和执行入口。
- 是否包含团队协作规范、代码规范、文档说明。
